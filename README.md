# HydroGeo Tools

Plugin para QGIS voltado a análises hidrológicas, territoriais e geoespaciais, com ferramentas para recursos hídricos, relevo, drenagem e microbacias.

## Versão disponível

**HydroGeo Tools v0.8.1**

A distribuição é realizada por repositório externo para o Gerenciador de Complementos do QGIS.

## Requisitos

- QGIS 4.0 ou superior
- Acesso à internet para instalação e atualização pelo repositório

## Instalação pelo QGIS

A instalação é feita diretamente pelo Gerenciador de Complementos.

1. Abra o QGIS.
2. Acesse **Complementos > Gerenciar e Instalar Complementos**.
3. Abra **Configurações**.
4. Em **Repositórios de complementos**, clique em **Adicionar**.
5. Informe:

   **Nome:**
   HydroGeo Tools

   **URL:**
   https://jhonzerablack.github.io/hydrogeo-qgis/plugins.xml

6. Confirme.
7. Clique em **Recarregar todos os repositórios**.
8. Abra a aba **Tudo** ou **Não instalados**.
9. Pesquise por **HydroGeo Tools**.
10. Clique em **Instalar Complemento**.

A URL do repositório precisa ser cadastrada apenas uma vez.

## Atualizações

Quando uma nova versão estiver disponível, o próprio Gerenciador de Complementos do QGIS poderá indicar a atualização.

Para verificar manualmente:

1. Abra **Complementos > Gerenciar e Instalar Complementos**.
2. Abra **Configurações**.
3. Clique em **Recarregar todos os repositórios**.
4. Se houver uma nova versão, use **Atualizar complemento**.
